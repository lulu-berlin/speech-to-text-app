# 0014 — Build tooling: Gradle catalog, no wrapper, flake scope

Status: accepted (flake-scope part superseded by 0016; wrapper and Gradle-version parts scoped by 0048) · Date: 2026-10-05

## Context
Roadmap item 02 fixes how the backend is built and how much of the Nix flake lands in item 02. Questions raised in consultation: Gradle version catalog yes/no, Gradle wrapper vs the devenv-provided Gradle, and whether the "minimal flake.nix that builds both parts" fits item 02 or should move to item 16 (today's nixpkgs documents `gradle.fetchDeps` with a MITM lockfile `deps.json` and an `updateScript` for generating it).

## Decision
- **Version catalog: yes.** Dependency versions live in `gradle/libs.versions.toml`; `build.gradle.kts` uses catalog references.
- **No Gradle wrapper.** Development builds run the devenv-provided Gradle (currently 8.14.4, ADR 0010); the Nix build (item 16) runs nixpkgs' own `gradle` through `gradle.fetchDeps`. A wrapper would add a committed binary and a second version source that participates in neither build.
  - *Scoped by [0048](0048-gradle-9-everywhere-root-wrapper-for-humans.md) (2026-10-12):* the rule governs agents, which always build with the devenv's Gradle; item 33 adds a root `gradlew` for human developers without Nix. All three paths (flake, devenv, wrapper) now run one Gradle, 9.8.0, so the "second version source" is checked rather than avoided.
- **Flake scope in item 02: both parts.** `flake.nix` in item 02 builds the backend (gradle deps via `gradle.fetchDeps` + `deps.json`) and the frontend (via `fetchPnpmDeps`); the combined app wrapper with all `STT_*` wiring and model assets is finished in item 16. The `deps.json` lockfile and pnpm store hash are generated by the user via the documented `updateScript`/hash commands, since Nix cannot run in the agent sandbox.

## Consequences
- Every dependency bump is a one-line catalog edit; `deps.json` must be regenerated when the catalog changes (user-run nix command).
- Dev and Nix builds may use different Gradle versions (devenv pin vs nixpkgs pin); both are 8.x today, divergence is tolerated and revisited if it causes trouble.
  - *Superseded by [0048](0048-gradle-9-everywhere-root-wrapper-for-humans.md):* dev, Nix and the wrapper run the same Gradle (9.8.0); `./gradlew checkVersions` and the flake's `versions-sync` check catch drift.
- Item 02's acceptance criterion is `nix build .` succeeding on both derivations; the wrapper and `nix run .` remain item 16.
