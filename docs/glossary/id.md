# Indonesian (id) — glossary

The term evidence is recorded in `docs/reviews/id.md`; this is the shared vocabulary. Six products
are compared in this cycle (Google 1, Microsoft 2, Firefox 3, VLC 4, LibreOffice 5, GNOME 6, ranked
in `docs/reviews/id.md`), so a row records the wording each product uses for that term; a `—` means
no product wording was recorded for that term.
