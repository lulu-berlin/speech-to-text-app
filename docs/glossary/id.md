# Indonesian (id) — glossary

The term evidence is recorded in `docs/reviews/id.md`; this is the shared vocabulary. Google's
Indonesian account page is the only product compared in this cycle, so a row records its wording
where the same word appears there; a `—` means no wording was recorded for that term.
