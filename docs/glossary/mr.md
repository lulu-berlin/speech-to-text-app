# Marathi (mr) — glossary

The term evidence is recorded in `docs/reviews/mr.md`; this is the shared vocabulary. Apple's
`mr-in` support articles are the only Marathi product UI found, so a row records Apple's wording
where the same word appears there; a `—` means the term is the neutral Marathi word, not a
product's.
