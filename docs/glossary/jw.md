# Javanese (jw) — glossary

The term evidence is recorded in `docs/reviews/jw.md`; this is the shared vocabulary. Google's
Search interface is the only Javanese product UI found (its account and help pages fall back), so a
row records its wording where the same word appears there; a `—` means no wording was recorded for
that term.

Interface loans accepted as Javanese technical writing uses them, with no separate row each:
`status`, `filter`, `tema`, `notifikasi`, `aplikasi`, `layanan`, `kolom`, `permanen`, `klik`,
`pilihan`, `lanjutan`, `transkrip`, `transkripsi`, `setelan`, `riwayat`, `antrian`, `segmen`,
`thread`.

This glossary is the Javanese layer; the same neutrality rule as the other locales applies (see
`docs/style-guides/jw.md`).
