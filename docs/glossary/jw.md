# Javanese (jw) — glossary

The term evidence is recorded in `docs/reviews/jw.md`; this is the shared vocabulary. Two
Javanese product UIs were found: Google's Search interface and the Javanese Wikipedia's interface
(MediaWiki's Javanese messages) — Google's account and help pages fall back, and part of Wikipedia's
messages is still Indonesian — so a row records their wording where the same word appears there; a
`—` means no wording was recorded for that term. Where the products' word is ngoko and the shared
term is krama (search, edit, rename), the wording stays as evidence and the krama term stands.

Interface loans accepted as Javanese technical writing uses them, with no separate row each:
`status`, `filter`, `tema`, `notifikasi`, `aplikasi`, `layanan`, `kolom`, `permanen`, `klik`,
`pilihan`, `lanjutan`, `transkrip`, `transkripsi`, `setelan`, `riwayat`, `antrian`, `segmen`,
`thread`.

This glossary is the Javanese layer; the same neutrality rule as the other locales applies (see
`docs/style-guides/jw.md`).
