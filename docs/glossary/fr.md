## Gender and culture

- No generic masculine and no inclusive point forms: epicene wording only (`voix`, `prise de
  parole`). The compared products' `intervenant`/`locuteur`
  stay in the review page as evidence; they are never adopted (user policy 2026-11-12: the
  comparison is for idiomatic wording only).
- Participles agree with the file or the task they describe, never with a person.
- `vous` address; no idioms, no culture-specific examples; `Speech-to-Text` stays untranslated.
