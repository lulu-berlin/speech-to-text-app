# Chinese (Traditional) (zh-Hant) — glossary

The term evidence is recorded in `docs/reviews/zh-Hant.md`; this is the shared vocabulary. The
compared products and their popularity are listed there (Google 1, Microsoft 2, Apple 3, Zoom 4,
Otter 5, Descript 6, Amberscript 7).
