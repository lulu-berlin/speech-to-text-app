## Gender and culture

- No generic masculine. `voz`/`voces`, `intervención`; `hablante` from the products is
  evidence only and never used. The comparison is for idiomatic wording only: a
  non-gender-neutral or culturally insensitive term is never accepted, even when a product uses
  it.
- `tú` address; no idioms or culture-specific examples; `Speech-to-Text` stays untranslated.
- Participles agree with the file or task, never with a person.
