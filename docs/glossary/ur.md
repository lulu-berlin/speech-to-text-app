# Urdu (ur) — glossary

The term evidence is recorded in `docs/reviews/ur.md`; this is the shared vocabulary. Google's
Urdu account page is the only product compared in this cycle (Apple's `ur-pk` pages redirect to
English), so a row records its wording where the same word appears there; a `—` means no wording
was recorded for that term.
