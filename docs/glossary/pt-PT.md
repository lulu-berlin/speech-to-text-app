# Portuguese (Portugal) (pt-PT) — glossary

The term evidence for the shared vocabulary is in `docs/glossary/pt-BR.md` and
`docs/reviews/pt-BR.md`; this file records the European Portuguese terms and the products'
Portuguese (Portugal) wordings. The compared products and their popularity are listed in
`docs/reviews/pt-PT.md` (Google 1, Microsoft 2, Apple 3, Mozilla Firefox 4, VLC 5, GIMP 6,
GNU nano 7).

| English                | Portuguese (Portugal)                              | Evidence                                        | Note                                                                                            |
| ---------------------- | -------------------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| settings               | definições                                         | Google 1: „Definições“; Apple 3: „Definições“   | replaces the Brazilian `configurações`                                                          |
| file                   | ficheiro                                           | Microsoft 2: „Ficheiro“; Google 1: „Ficheiro“   | replaces the Brazilian `arquivo`                                                                |
| delete                 | eliminar                                           | Apple 3: „Eliminar“; Google 1: „Eliminar“       | replaces the Brazilian `excluir`                                                                |
| save                   | guardar                                            | Google 1: „Guardar“                             | replaces the Brazilian `salvar`                                                                 |
| download | transferir | Microsoft 2: „Transferir“ | replaces the Brazilian `baixar` |
| upload                 | carregar                                           | Google Drive 1: „Carregar“                      | the same verb in pt-BR                                                                          |
| default                | predefinido                                        | Google 1: „Predefinido“                         | replaces the Brazilian `padrão` in this sense                                                   |
| screen                 | ecrã                                               | Microsoft 2: „Ecrã“; Apple 3: „Ecrã“            | replaces the Brazilian `tela`                                                                   |
| user                   | utilizador                                         | Microsoft 2: „Utilizador“                       | replaces the Brazilian `usuário`                                                                |
| connection             | ligação                                            | Google 1: „Ligação“                             | replaces the Brazilian `conexão`; the verb is `ligar`                                           |
| access                 | aceder                                             | Google 1: „Aceder“                              | replaces the Brazilian `acessar`                                                                |
| application            | aplicação                                          | Microsoft 2: „Aplicação“                        | replaces the Brazilian `aplicativo`                                                             |
| progress phrase        | a + infinitive                                     | Google 1: „A carregar…“, „A processar…“         | never the gerund (`carregando`), which is Brazilian                                             |
| speaker(s) | falante / falantes | Google 1: „falante“; Microsoft 2: „orador“ | common-gender (`-e`), no `o/a`; Microsoft's gendered `orador` stays evidence only; shared with pt-BR |
| diarization            | identificação de falantes                          | Google 1: „identificação de falantes“           | shared with pt-BR                                                                               |
| threads | threads | Microsoft 2; GIMP 6: „linhas de execução (threads)“ | the loanword, kept inside GIMP's parenthetical form; shared with pt-BR |
| queue phases           | a dividir / a transcrever / a identificar falantes | Google 1: „A processar…“                        | the same nouns as pt-BR after `durante`                                                         |
| save / discard         | guardar / descartar                                | Google 1, Apple 3                               | ready for access keys G and D when the keys are added                                           |
| default user interface | interface do utilizador predefinida                | Google 1: „Interface“; user decision 2026-11-13 | `frontend` never appears in any language; `interfaz`/`interface`/`ממשק` in the sibling catalogs |
| upload (TUI, queue) | enviar / envio | catalog: „A enviar {filename}“, „Envios“; Apple 3: „Enviar e descarregar ficheiros“ | the action of sending a file; `carregar` stays for loading („A carregar transcrição…“), although Microsoft's OneDrive button is „Carregar“ |
| search | pesquisar | catalog: „Pesquisar“; Firefox 4: „Pesquisar“; nano 7: „Procurar“ | the catalog's `pesquisar`, as Firefox writes it, not nano's `procurar` |
| pause / resume         | pausar / retomar                                   | catalog: „Pausar a fila“, „Retomar“             | verbs for the buttons and hints; the action nouns are `pausa` and `retoma`                     |
| folder | pasta | nano 7: „pasta“, „Ir para pasta“ | chosen over `diretório`; the file browser uses it |
| format | formato | nano 7: „Formato DOS“ | — |

This glossary is the European-Portuguese layer; every term not listed here takes its wording
from `docs/glossary/pt-BR.md`.
