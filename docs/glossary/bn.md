# Bengali (bn) — glossary

The term evidence is recorded in `docs/reviews/bn.md`; this is the shared vocabulary. The
compared products and their popularity are listed there (Google 1, Microsoft 2, Firefox 3,
VLC 4, GNOME Files 5, GNOME Terminal 6).

This glossary is the Bengali layer; the same neutrality rule as the other locales applies (see
