# Tamil (ta) — glossary

The term evidence is recorded in `docs/reviews/ta.md`; this is the shared vocabulary. Apple's
`ta-in` iPhone/iPad user guides are fully Tamil and are the only product compared in this cycle, so
a row records its wording where the same word appears there; a `—` means no wording was recorded
for that term.

| transcription           | டிரான்ஸ்கிரிப்ஷன்                                                     | —                                   |                                                              |

`docs/style-guides/ta.md`).
