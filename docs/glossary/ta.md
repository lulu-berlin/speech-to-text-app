# Tamil (ta) — glossary

The term evidence is recorded in `docs/reviews/ta.md`; this is the shared vocabulary. Apple's
`ta-in` iPhone/iPad user guides, Firefox's Tamil locale, VLC, GNOME Files, gedit and SoundScript.AI
supply the wording recorded here; a `—` means no wording for that term was found in the products
compared.

This glossary is the Tamil layer; the same neutrality rule as the other locales applies (see
`docs/style-guides/ta.md`).
