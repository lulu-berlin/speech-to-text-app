# Bengali (bn) — translation review

Standard (user decision 2026-11-12): every string is compared with a similar app or feature in
the product's own Bengali UI, for idiomatic wording only; more popular products rank higher. A
non-gender-neutral or culturally insensitive term is never accepted, even when a compared product
uses it: the product's wording stays here as evidence and the catalog uses a neutral alternative.
The mechanical parity check (keys, placeholders, ICU, plural categories) is the standing gate.

## Products compared (popularity, 1 = most popular)

1. Google Workspace (Docs/Drive/Meet) — Bengali UI: upload, search, transcripts, player controls.
2. Microsoft (Teams/Word) — Bengali UI: meeting transcripts, connection states, settings.

Only the products whose wording this record actually cites are listed; a product joins the list
when its Bengali wording for a term is recorded below.

Bengali verbs carry no gender agreement and imperatives (`করুন`, `বেছে নিন`, `মুছুন`) address
nobody in particular, so instructions are neutral by form. `স্পিকার` is an ungendered loanword:
it names the person who speaks and never the reader. Sentences end with the danda `।`; Latin
words keep a half-width space in running text, while a Bengali case suffix attaches to a
placeholder with a hyphen and no space (`{filename}-এর`, `{number}-এর`). The editor's shortcut
check requires one underlined letter per button, so the buttons show `সংরক্ষণ (S)` and
`বাতিল (D)`.

"Compared" gives the product whose terminology this string reuses; `—` means the string is a
phrase no compared product writes, and only the catalog's own terminology applies. "Audit" gives
the neutrality result, then any layout, order or shortcut note.
