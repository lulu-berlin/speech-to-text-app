# Portuguese (Portugal) (pt-PT) — translation review

Standard (user decision 2026-11-12): every string is compared with a similar app or feature in
the product's own Portuguese (Portugal) UI; more popular products rank higher; every string is
audited for gender neutrality and cultural sensitivity. The mechanical parity check (keys,
placeholders, ICU, plural categories) is the standing gate.

This catalog starts from the reviewed `pt-BR` catalog and changes the European Portuguese
layer. Google serves Brazilian Portuguese at `hl=pt-PT`, so the Portuguese (Portugal)
wordings verified so far are Apple's and Microsoft's support pages; the table records it where a comparable
control was found and `—` where no wording has been recorded yet — the per-string fill
continues, pt-PT first. The European wording is not yet checked by a native European
Portuguese speaker; that check stays best effort, as the standard says.

## Products compared (popularity, 1 = most popular)

1. Google — serves Brazilian Portuguese at `hl=pt-PT`; not a Portuguese (Portugal) wording.
2. Microsoft (`support.microsoft.com/pt-pt`) — verified Portuguese (Portugal) wording:
   „transcrição“, „Transferir“, „Eliminar“, „orador“, „Parar“.
3. Apple (`support.apple.com/pt-pt`) — verified Portuguese (Portugal) wording: „Definições“,
   „dispositivo“, „descarregar“, „ficheiros“, „Apagar“.
4. GNU nano (`pt.po`, Translation Project, 9.3-pre1) — European Portuguese terminal UI: verified
   wording: „Ajuda“, „Fechar“, „Cancelar“, „Procurar“, „Sair“, „Abrir“, „Gravar“, „Recuar“,
   „Seguinte“/„Anterior“, „pasta“, „explorador de ficheiros“, „Ir para pasta“, „Marcar texto“,
   „Formato DOS“, „Opção“, „predefinição“, „histórico“.

Tone: no `você`; the UI leaves the actor out and buttons are infinitives (`Guardar`,
`Eliminar`), as the European products write them.
