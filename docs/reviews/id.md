# Indonesian (id) — translation review

Standard (user decision 2026-11-12): the record holds the comparison found per string with a
similar app or feature in the product's own Indonesian UI, for idiomatic wording only. The
Compared column names the product and the wording it uses; a dash means no comparison was found,
and a product name never appears without its wording. The mechanical parity check (keys,
placeholders, ICU, plural categories) is the standing gate.

## Products compared (popularity, 1 = most popular)

1. Google — the fully Indonesian account page (`myaccount.google.com/intro?hl=id`): „Setelan“,
   „perangkat“, „tugas“, and the Indonesian Google Cloud, Google Workspace Drive API and Google
   Analytics developer documentation: „antrean“, „Menetapkan kolom label“, „Memindahkan file dan
   folder ke sampah atau menghapusnya“, „antarmuka pengguna“, „Lainnya“.
2. Microsoft — the Indonesian Word/OneNote transcription help
   (`support.microsoft.com/id-id/word/transcribe-your-recordings`): „Transkripsi“, „Pembicara 1“,
   „label pembicara“, „Unggah audio“, „Edit bagian transkrip“, „Ubah semua Pembicara [x]“,
   „File yang Ditranskripsikan“, „Jeda rekaman“, „Lanjutkan rekaman“; the PowerPoint speaker notes
   page: „catatan pembicara“; the Indonesian Excel and Task Scheduler docs: „Ganti Nama“, „Secara
   default“, „waktu menganggur“, „sedang berjalan“, „status setiap tugas“; and the Indonesian
   Windows Terminal overview: „Terminal Windows“, „PowerShell“.
3. Mozilla Firefox — the Indonesian localization in `mozilla-l10n/firefox-l10n`
   (`browser/browser/downloads.ftl`, `browser/browser/preferences/preferences.ftl`,
   `browser/browser/places.ftl`): „Jeda“, „Lanjutkan“, „Dijeda“, „Dibatalkan“, „Gagal“, „Selesai“,
   „Batalkan“, „Riwayat“, „Pulihkan Bawaan“, „Otomatis (gunakan pengaturan sistem)“, „Unduhan“,
   „Kesalahan Unduhan“, „Berkas dihapus“, „Edit…“, „coba lagi“.
4. VLC — `po/id.po` in the VideoLAN repository: „Batal“, „Simpan“, „Hapus“, „Buka“, „Cari“,
   „Bantuan“, „Keluar“, „Kembali“, „Format“, „Transkrip“, „Default“, „Filter“, „Pilih“, „Folder“,
   „Buka Folder“, „Audio“.
5. LibreOffice — `source/id/cui/messages.po` and `source/id/svx/messages.po` in
   `LibreOffice/translations`: „Tutup“, „Tema“, „Atur Ulang“, „Kembalikan“, „Tetap“, „Halaman“,
   „Mulai“, „Akhir“, „Opsi“, „Tandai“, „Segmen“, „Keterangan“, „Naik“, „Menunggu“, „Perintah“,
   „Jalur“, „Simpan“, „Ubah urutan halaman“, „yang dipilih“, „Tempel“.
6. GNOME — the Indonesian Nautilus/Berkas catalog `po/id.po` on the GNOME GitLab: „Gabungkan
   folder“, „Pindahkan ke Sini“, „Batal“, „Buka Folder“.

Indonesian verbs carry no grammatical gender, and no title or pronoun addresses the reader.
Every string was checked for cultural sensitivity: nothing loaded; the register and calque slips the copy review found (`punya`, `Tugas menunggu`,
`Perubahan tersimpan`) were fixed in the same cycle. The editor's shortcut check requires one underlined letter per button, so the
buttons show Simpan (S) and Buang (D).
