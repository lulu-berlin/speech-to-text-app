# Russian (ru) — translation review

Standard (user decision 2026-11-12): every string is compared with a similar app or feature in
the product's own Russian UI, for idiomatic wording only; more popular products rank higher. A
non-gender-neutral or culturally insensitive term is never accepted, even when a compared product
uses it: the product's wording stays here as evidence and the catalog uses a neutral alternative.
The mechanical parity check (keys, placeholders, ICU, plural categories) is the standing gate.

## Products compared (popularity, 1 = most popular)

1. Google Workspace (Docs/Drive/Meet) — Russian UI: upload, search, transcripts, player controls.
2. Microsoft (Teams/Word) — Russian UI: meeting transcripts, connection states, settings.
3. Apple (macOS/iOS) — Russian UI: dictation, playback, editing.
4. GNU nano — Russian UI: key reference, file browser, status-line messages (it ships with most
   Linux systems).

Only the products whose wording this record actually cites are listed.

Buttons are infinitives (`Сохранить`, `Удалить`), and the cancel button is the noun `Отмена`; neither form carries gender; verbs and
adjectives agree with the noun they describe — `задача` (f), `файл` (m), `очередь` (f) — never
with the reader. The speaker noun `спикер` is a loanword, masculine in form and used generically.
Quotation marks are `«…»` when a control's own name is quoted; Latin words keep a half-width space
(`CPU`, `{filename}`). The editor's shortcut check requires one underlined letter per button, so
the buttons show `Сохранить (S)` and `Не сохранять (D)`. In the TUI a message is a sentence and
starts with a capital letter; only the fragments that continue a file name (`tui.notice.*Rest`)
keep the English lowercase, as the inline statuses `в очереди` and `готово` do.

Verified wording: Google „расшифровка“, „настройки“, „устройствах“, „файл“, „Остановить“, „Поиск“, „Скачайте“, „Приостановить“; GNU nano „Справка“, „Выход“, „Отмена“, „Сохранить“, „Поиск“, „Удалить“, „Назад“, „Закрыть“.

"Compared" gives the product whose terminology this string reuses; `—` means no comparison is recorded yet. "Audit" gives the neutrality result, then any note.
