# Urdu (ur) — translation review

Standard (user decision 2026-11-12): the record holds the comparison found per string with a
similar app or feature in the product's own Urdu UI, for idiomatic wording only. The Compared
column names the product and the wording it uses; a dash means no comparison was found, and a
product name never appears without its wording. The mechanical parity check (keys, placeholders,
ICU, plural categories) is the standing gate.

## Products compared (popularity, 1 = most popular)

1. Google — its products' Urdu strings: Chrome's interface (`chrome/app/resources/generated_resources_ur.xtb`
   and `chromium_strings_ur.xtb`, paired with the `en-GB` files), Android's framework and Settings
   strings (`core/res/res/values-ur/strings.xml`, `Settings/res/values-ur/strings.xml`) and the Urdu
   account page (`myaccount.google.com/intro?hl=ur`): „موقوف کریں“، „دوبارہ شروع کریں“، „ترتیبات“،
   „حذف کریں“. Microsoft and Apple were not compared: Microsoft support serves no Urdu wording
   checked in this cycle, and Apple's `ur-pk` pages redirect to `en-us`.
2. Wikipedia — MediaWiki's Urdu interface messages (`languages/i18n/ur.json`): „ترمیم“، „تاریخچہ“،
   „انضمام“، „قطعہ“، „راستہ“. The Urdu Wikipedia supplies the editing, history, upload and file
   wording where the terminal has no closer equivalent.

The terminal's strings (`tui.*`) were compared with these two products' Urdu wording. Where the TUI
concept has no direct control in either UI, the closest feature is recorded: the download panel's
empty state for the empty queue, its format chooser for the `[Tab] format` hint, its selected-item
label for the marked speaker. No Urdu translation of a terminal program could be cited: the
Translation Project lists no Urdu catalog for nano (`translationproject.org/domain/nano.html` has
no Urdu row), GNOME's Urdu archive for GNOME 51 holds only `.pot` files with no Urdu `nautilus.po`,
and VLC's `po/ur.po` carries 23 translated strings, none of the controls used here. Key labels
themselves are the program's bindings and stay as English writes them.

The interface is right to left; Latin placeholders keep their own direction. Urdu imperatives
carry no grammatical gender, and no title or pronoun addresses the reader. Every string was
checked for cultural sensitivity: nothing loaded, no register drift. The editor's shortcut
check requires one underlined letter per button, so the buttons show محفوظ کریں (S) and نظر
انداز کریں (D).
