# Marathi (mr) — translation review

Standard (user decision 2026-11-12): the record holds the comparison found per string with a
similar app or feature in the product's own Marathi UI, for idiomatic wording only. The Compared
column names the product and the wording it uses; a dash means no comparison was found, and a
product name never appears without its wording. The mechanical parity check (keys, placeholders,
ICU, plural categories) is the standing gate.

## Products checked (popularity, 1 = most popular)

1. Google (Meet) — answers `hl=mr` in Hindi, so no Marathi wording exists to compare.
2. Microsoft (support) — serves no Marathi pages.
3. Apple (`support.apple.com/mr-in`) — fully translated Marathi articles: „सेटिंग्ज“, „डिव्हाइस“,
   „हटवा“, „रद्द करा“, „डाउनलोड“, „प्ले करा“, „शोधा“, „पर्याय“, „सूचना“, „निवडा“. It is the only
   product with Marathi UI text, so its wording is recorded wherever the app uses the same word.

Marathi imperatives carry no grammatical gender, and no title or pronoun addresses the reader;
sentences about the neuter `कार्य` agree in the neuter. Every string was checked for cultural
sensitivity: no Hindi-dominant idiom, no Sanskritised register and nothing loaded. The editor's
shortcut check requires one underlined letter per button, so the buttons show जतन करा (S) and
टाकून द्या (D).
