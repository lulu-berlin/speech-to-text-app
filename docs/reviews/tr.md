# Turkish (tr) — translation review

Standard (user decision 2026-11-12): the record holds the comparison found per string with a
similar app or feature in the product's own Turkish UI, for idiomatic wording only; more popular
products rank higher. A dash in the Compared column means no comparison was found. The
mechanical parity check (keys, placeholders, ICU, plural categories) is the standing gate.

## Products compared (popularity, 1 = most popular)

1. Google Workspace (Docs/Drive/Meet) — Turkish UI: upload, transcripts, speaker identification,
   history, settings.
2. Microsoft (Teams/Word) — Turkish UI: meeting transcripts, connection states, settings.
3. Apple (macOS/iOS) — Turkish UI: playback, folders, paths.
4. GNU coreutils — Turkish gettext catalog: moving, sorting, renaming, paths.
5. GNU nano — Turkish gettext catalog: terminal help, search, save, cancel, close, back.
6. VLC media player — Turkish gettext catalog: playback, pause and resume, themes, settings,
   saved files.
7. GNOME Files (Nautilus) — Turkish gettext catalog: file browser, move, retry, reset, select,
   filter, loading and saving errors.

Turkish has no grammatical gender; the speaker noun is konuşmacı (the voice's source), and no
sentence can address the reader with a gendered form. Buttons are imperatives (`Kaydet`, `Sil`) and `İptal` is a noun; neither form carries
gender. The editor's shortcut check requires one underlined letter per button, so the
buttons show Kaydet (K) and Bırak (B).
