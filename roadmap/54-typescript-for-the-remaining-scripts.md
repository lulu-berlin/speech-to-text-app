# 54 — TypeScript for the remaining hand-written JavaScript

Status: draft
Depends on: — (ADR [0054](../docs/decisions/0054-no-hand-written-javascript.md), which lands with item
[50](../docs/specs/electron-desktop-app.md))
Blocks: —

## Goal

The scripts written before ADR 0054 follow it: every hand-written JavaScript file outside item 50
becomes TypeScript, run directly by Node (type stripping) or compiled where its syntax needs it, and
its package's test command type-checks it with `tsc --noEmit`. No behavior changes.

## Evidence

Hand-written JavaScript left after item 50 (tracked files, 2026-10-15):

- `docs/check-links.mjs` (83 lines), `docs/check-architecture-names.mjs` (229),
  `docs/check-architecture-diagram.mjs` (137), `docs/markdown-lines.mjs` (12) — the documentation
  checks AGENTS.md § Commands runs from the repository root.
- `e2e/check-playwright.mjs` (110, run by `pnpm test` in `e2e/`), `e2e/global-setup.mjs` (108,
  Playwright's `globalSetup`), `e2e/lib/backend.mjs` (341, the e2e backend harness).
- `frontend/mock/mockServiceWorker.js` is generated by `msw init` and is not ours (ADR 0054's
  exception).
- Node 24.21.0 (devenv and CI, `versions.json`) runs `.ts` directly; item 50 sets up the pattern
  (`erasableSyntaxOnly`, `allowImportingTsExtensions`, `tsc --noEmit` in `pnpm test`).

## Proposal

1. Convert each file to `.ts` with types, keeping its behavior and output.
2. Give `e2e/` a `tsconfig.json` and `typescript`, and run `tsc --noEmit` in its `pnpm test`; the
   documentation checks get their own `tsconfig.json` (they run from the repository root without a
   package) — or a package, to be decided.
3. Update every caller: AGENTS.md § Commands, `e2e/package.json`, `e2e/playwright*.config.ts`, CI.

## Open questions

- Do the documentation checks get a package (`docs/package.json` with `typescript`) or a root
  `tsconfig.json` checked by the devenv's global `tsc` (ADR 0010)?
- Does the e2e `tsc --noEmit` include the existing specs (which may surface type errors in code
  from earlier items) or only the converted scripts at first?

## Test list (proposed; behaviors only)

- [ ] The documentation checks report exactly what they reported before, on the current tree and on
      a tree with a broken link, a missing code name and a wrong diagram arrow
- [ ] The e2e suite boots the backend and runs as before (`pnpm test` in `e2e/`, the Linux e2e)
- [ ] A type error in any converted script fails its package's test command
- [ ] (must not break) `gradle check`, `pnpm test` (frontend, e2e), CI

## Acceptance criteria

- No hand-written `.js`/`.mjs`/`.cjs` file remains outside generated third-party files; callers and
  docs updated; type checks in the standard test commands.
- All test-list items ticked and green; user approved the diff.
